# Monu Mobile Solution (MMS) - Web Portal & POS System

हजरतगंज, लखनऊ स्थित **Monu Mobile Solution** के लिए तैयार की गई आधुनिक मोबाइल रिपेयरिंग डेमो वेबसाइट, व्हाट्सएप लीड जेनरेशन, और स्टाफ POS/इन्वेंट्री मैनेजमेंट सिस्टम।

---

## 🌟 मुख्य विशेषताएं (Key Features)

### 1. पब्लिक वेबसाइट (Public Frontend)
* **प्योर लाइट थीम (Strictly Light Theme):** क्लीन व्हाइट और प्रीमियम रॉयल ब्लू डिज़ाइन।
* **हिन्दी / English स्विचर:** 1-क्लिक में पूरी वेबसाइट भाषा बदलने की सुविधा।
* **मोबाइल बॉटम नेविगेशन डॉक:** मोबाइल स्क्रीन पर नेटिव ऐप जैसा अनुभव (Home, Services, Calculator, Status, WhatsApp)।
* **इंस्टेंट रिपेयर कॉस्ट कैलकुलेटर:** ब्रांड ➔ मॉडल ➔ समस्या ➔ रेट व 1-क्लिक व्हाट्सएप बुकिंग।
* **लाइव रिपेयर स्टेटस ट्रैकर:** जॉब टोकन (उदा. `MMS-1001`) या मोबाइल नंबर से लाइव प्रोग्रेस बार।
* **व्हाट्सएप लीड जनरेशन:** फ्लोटिंग व्हाट्सएप बटन और डायरेक्ट इंक्वायरी फॉर्म (नंबर: `7905859701`)।
* **इंस्टाग्राम लाइव शोकेस:** हालिया रिपेयरिंग, डिलीवरी और एक्सेसरीज का इंटरेक्टिव ग्रिड।
* **लोकेशन व मैप्स:** 216, 2nd Floor, Sree Rama Towers, Ashok Marg, Hazratganj, Lucknow (Google Maps Embed सहित)।

### 2. स्टाफ बैकएंड व पीओएस पोर्टल (Staff Management Portal)
* **तीनों लॉगिन रोल्स:**
  1. **एडमिन (Admin):** `7905859701` | पासवर्ड: `Mms@859701` (फुल एक्सेस, बैलेंस शीट, P&L, डेली सेल्स)
  2. **मैनेजर (Manager):** `9988772211` | पासवर्ड: `Mms@772211` (स्टॉक रिफिल, बिलिंग, खाता-बही)
  3. **फ्रंट डेस्क (Front Desk):** `9955443311` | पासवर्ड: `Mms@443311` (टोकन बनाना, POS बिलिंग)
* **ऑटो-स्टॉक डिडक्शन:** बिलिंग होते ही इन्वेंट्री से सामान अपने-आप घट जाता है।
* **लो-स्टॉक चेतावनी (Low Stock Warning):** 2 पीस से कम होने पर लाल अलर्ट।
* **स्टॉक रिफिलिंग (Restock):** नया माल आने पर 1-क्लिक में क्वांटिटी बढ़ाएं।
* **उधार / खाता-बही (Credit Ledger):**
  - ग्राहक-वार बकाया राशि रिकॉर्ड।
  - 'Receive Payment' से हिसाब चुकता।
  - 1-क्लिक व्हाट्सएप पेमेंट रिमाइंडर।
* **डेली सेल्स व गल्ला क्लोजिंग:** आज का कुल कैश, UPI और उधार, साथ ही ओनर को व्हाट्सएप समरी।
* **बैलेंस शीट & P&L:** दुकान की कुल स्टॉक वैल्यूएशन (CP & SP), मार्जिन %, और Excel/JSON बैकअप।

## 🚀 क्लाउडफ्लेयर पेजेस (Cloudflare Pages) पर 100% फ्री लाइव करने का तरीका

### तरीका 1: ऑटोमैटिक बैट फाइल (1-Click)
Windows पर `deploy-to-cloudflare.bat` पर डबल क्लिक करें।

### तरीका 2: Wrangler CLI कमांड
टर्मिनल / PowerShell में यह कमांड चलाएं:
```bash
npx wrangler pages deploy monu-mobile-solution --project-name monu-mobile-solution
```

### तरीका 3: Cloudflare Dashboard डायरेक्ट अपलोड
1. [dash.cloudflare.com](https://dash.cloudflare.com) पर लॉगिन करें।
2. **Workers & Pages** ➔ **Create Application** ➔ **Pages** ➔ **Upload Assets** पर जाएं।
3. प्रोजेक्ट का नाम `monu-mobile-solution` रखें।
4. `monu-mobile-solution` फोल्डर को ड्रैग-एंड-ड्रॉप कर दें।
5. वेबसाइट तुरंत `https://monu-mobile-solution.pages.dev` पर लाइव हो जाएगी!
